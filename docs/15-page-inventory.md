## 6. Loading states

| Context                        | Pattern                                                                                                                       | Detail                                                                                                                          |
| ------------------------------ | ----------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| Route transitions (storefront) | `loading.tsx` with **content-shaped skeletons**                                                                               | PLP: 8 skeleton cards (image 4:5 + 3 text lines); PDP: gallery block + text blocks; Account: card skeletons                     |
| PPR dynamic islands            | Suspense fallbacks sized to the final content (no CLS)                                                                        | PDP price/stock: skeleton text 80 px wide; "Fits your routine": hidden until resolved (no placeholder, to avoid a false signal) |
| Cart mutations                 | Optimistic UI (`useOptimistic`); line shows a subtle spinner on the qty control; rollback + toast on failure                  |                                                                                                                                 |
| Add to cart button             | Loading state (spinner, label kept) → success check (1.2 s)                                                                   |                                                                                                                                 |
| Finder step save               | Non-blocking; a "Saved" indicator on failure-retry; Next is enabled immediately (autosave queue)                              |                                                                                                                                 |
| Finder analyzing               | Dedicated page with staged status messages from SSE; a minimum display of 1.5 s so it doesn't flash                           |                                                                                                                                 |
| Checkout                       | Skeleton of the Stripe form (fields) until the embed mounts; the summary renders server-side instantly                        |                                                                                                                                 |
| Checkout return                | "Confirming your payment…" with a progress indicator; polling up to 10 s                                                      |                                                                                                                                 |
| Admin tables                   | Skeleton rows (10) keeping the column widths; on filter change, the table dims to 60% with a top progress bar (keeps context) |                                                                                                                                 |
| Admin charts                   | Skeleton chart frame with axis placeholders                                                                                   |                                                                                                                                 |
| Admin forms submit             | Button loading state; form disabled (`fieldset disabled`)                                                                     |                                                                                                                                 |
| Image loading                  | Blur placeholder (`blurDataUrl`) → fade in 200 ms                                                                             |                                                                                                                                 |
| Global navigation              | Top progress bar (NProgress-style, 2 px clay) on slow transitions > 300 ms                                                    |                                                                                                                                 |
