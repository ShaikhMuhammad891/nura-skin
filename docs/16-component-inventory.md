# 16 — Component Inventory

**Columns:** Component · Location · Type (**S** = Server Component, **C** = Client Component, **E** = email) · Responsibility · Key props / data · Notes (a11y, perf, states).
**Location key:** `ui/` = `src/components/ui` · `layout/` = `src/components/layout` · `shared/` = `src/components/shared` · `F:<x>` = `src/features/<x>/components`.

Rules: components are presentational unless their name ends in `Container`/`Section` (those load data, S only). Client components receive **serializable DTOs only**. Every interactive component has keyboard support and a Storybook-style playground in `/dev/components` (dev/staging only, P2).
