## 1. Summary of the most important changes

1. **The AI finder's latency budget was physically impossible.** It is now a two-phase streamed output: a small, validated **selection** renders first, and the prose explanations stream in afterwards. The fallback also degrades per step instead of discarding the whole routine.
2. **The per-request structured-output schema is now a static, index-based schema.** The model now picks `candidateIndex` 0–7, never product IDs. This keeps grammar compilation and prompt caching warm, and is an even stronger grounding guarantee.
3. **The CSP nonce strategy would have made every page dynamic**, disabling SSG/ISR/PPR. It is now a two-tier CSP.
4. **Cross-environment "build once, promote" doesn't work on Vercel** (public env vars are inlined at build time). It is now staged production deploys: build → smoke → promote.
5. **The subscription model contradicted Stripe's one-interval-per-checkout constraint.** It is now a single plan interval with quantity suggestions.
6. **The public admin demo contradicted mandatory staff MFA.** A `DEMO_STAFF` role now runs mutations that are rolled back.
7. **Stripe status mapping bugs.** Skip (`trialing`) and pause (`pause_collection` with `status=active`) were mis-mapped, and subscription-mode charges couldn't be found for refunds. The mapping is now explicit and the API version is pinned.
8. **Compliance gaps.** US consumer health-data laws, cookie consent timing, MoCRA reaction reporting, and returns were missing. These are now added as requirements and tables.
9. **Scope realism.** Honest re-estimate: 26–30 weeks for the full spec. A Release 1 cut line keeps an ~18-week portfolio launch.

## 3. Unrealistic assumptions (called out explicitly)

| Assumption in v1 docs                                      | Reality                                                                                                                | Now                                      |
| ---------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- | ---------------------------------------- |
| LLM writes 3 tiers of explanations in ≤ 8 s                | Output speed makes this ~3–5× too slow                                                                                 | Two-phase; p95 ≤ 10 s to a usable result |
| Per-request dynamic JSON schema is free                    | Structured outputs compile and cache grammars per schema, so unique schemas pay compilation each call and hurt caching | Static schema, index-based picks         |
| Nonce CSP + static pages                                   | Mutually exclusive in Next.js                                                                                          | Two-tier CSP                             |
| Promote staging → prod without a rebuild                   | Not possible with differing `NEXT_PUBLIC_*` values                                                                     | Staged prod deploy                       |
| Per-product subscription intervals in one checkout         | Stripe Checkout: one subscription, one interval                                                                        | Plan interval + quantities               |
| 3,000 LLM calls/day for a portfolio                        | ≈ $100+/day worst case with no revenue                                                                                 | 400/day cap + spend limit                |
| Per-role inactivity timeout in Clerk                       | Not supported per role; no activity claim                                                                              | First-factor age + step-up + client idle |
| ~210 retouched assets alongside the full build in 18 weeks | ~60–90 h of production work alone                                                                                      | ~90 in R1                                |
| Full spec in 17–19 weeks                                   | ~26–30 weeks                                                                                                           | R1 cut line at ~18 weeks                 |
| Analytics table partitioned "when it gets big"             | Retrofitting partitioning on a hot table is painful                                                                    | Partitioned from day one                 |

## 5. Architecture strengths confirmed (keep as-is)

- A **modular monolith** with feature boundaries, and services free of Next.js APIs, so they are reusable from webhooks and jobs.
- **Webhooks as the payment source of truth**, event-ID idempotency, convergent handlers and nightly reconciliation.
- **Inventory reservations + ledger + row locks.** This is the right model for serverless concurrency.
- The **grounded AI pipeline** (SQL hard filters → rule draft → constrained model → validator → fallback), now strengthened by index-based selection.
- **Permissions in code** + a generated role-matrix test for every admin endpoint.
- The **transactional outbox** for side effects.
- The **asset manifest + CI check** that makes "no placeholders" enforceable.
