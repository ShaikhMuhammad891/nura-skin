# 21 — Development Roadmap

**Assumptions:** one senior full-stack developer (optionally with AI coding assistance), about 30 focused hours/week. Estimates include tests and docs.

**Re-estimate (review R-22).** Summing realistic effort for the full spec (a product editor with an INCI parser, a full analytics suite, subscription lifecycle with test-clock suites, ~210 retouched assets, etc.) gives **≈ 26–30 weeks**, not 17–19. The original timeline is kept for the **Release 1 cut line** below, and everything else moves to Release 2. This keeps the portfolio piece shippable at ~18 weeks without watering down the parts reviewers actually probe (finder, checkout correctness, security, admin core).

|                  | **Release 1 (≈ 18 weeks): portfolio launch**                                                                                                                                                                                                           | **Release 2 (≈ +8–10 weeks)**                                                                                                                                                                             |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Storefront       | Home, PLP, PDP, routines, ingredient pages (seeded content), search, SEO                                                                                                                                                                               | Concern hubs, curated landing combos, `/about` polish                                                                                                                                                     |
| Finder           | Full engine, two-phase AI, fallback, swap, save, shade choice, evals                                                                                                                                                                                   | 90-day check-in, email-routine for guests (never, see R-16)                                                                                                                                               |

| Subscriptions    | Skip, pause/resume, change interval, cancel with save offer, reminder + dunning emails, renewal reservations                                                                                                                                           | Swap product, add extras to next box, change address                                                                                                                                                      |
| Account          | Overview, orders, subscriptions, routines, addresses, settings, export/delete, reviews (text only)                                                                                                                                                     | Review photos, wishlist sharing, skin profile editor                                                                                                                                                      |
| Returns / safety | Report a reaction + return request (basic)                                                                                                                                                                                                             | Full RMA workflow                                                                                                                                                                                         |
| Admin            | Dashboard, products (editor without the INCI parser: ingredients picked from a list), inventory + ledger, orders (fulfil, refund, cancel, notes), review moderation, coupons CRUD, core analytics (KPIs, revenue, finder funnel), audit log, demo mode | Bundles builder, ingredient DB editor, customer metrics/lifecycle, coupon generator, bulk fulfil, concern heatmap, team management UI (seeded roles in R1), finder debug viewer, abandoned checkouts view |
| Assets           | ~90 assets: all packshots + texture shots, 5 flat-lays, heroes, 6 lifestyle, 8 ingredient portraits, icons, empty-state illustrations                                                                                                                  | Angle and in-hand shots, remaining lifestyle, social and email extras                                                                                                                                     |
| Quality          | CUJ-01…09, 13, 14; axe; Lighthouse; AI eval; concurrency tests                                                                                                                                                                                         | Visual regression matrix, k6 suite beyond the checkout scenario, cross-browser nightly                                                                                                                    |

Milestones below describe the **full** scope. Items marked R2 in the table above are skipped in the Release 1 pass of each milestone.

**Sequencing logic:** foundations → data → identity → the catalogue that everything references → money path (cart → checkout) → the differentiator (finder) → retention (subscriptions and account) → operations (admin) → hardening. The two highest-risk areas (payments and AI) each get a **spike** early (M1.5 and M3.5) so surprises appear before the full build.
